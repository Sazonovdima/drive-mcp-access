Privacy Policy — Drive MCP Access

Last updated: November 13, 2026

Who uses this app

Drive MCP Access is a private tool used only by its owner to access the owner's own Google account. It is not offered to the public.

What data is accessed

With the owner's consent, the app accesses Google Drive files, Google Docs and Google Sheets in the owner's account, using the scopes granted on the Google consent screen.

How data is used

Data is used only to let the owner's AI assistant read, organize and, at the owner's request, edit the owner's documents. OAuth tokens are stored locally on the owner's computer.

Sharing

Google user data is not sold, not used for advertising and not shared with third parties, except for processing by the AI assistant the owner uses to work with the documents.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
